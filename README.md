# Nithishduda-ai Tap

This tap publishes Homebrew formulae for nithishduda-ai projects.

## Available Formulae

- `pagerduty-oncall-ack`: installs the `pd-auto-ack` CLI with terminal dashboard support.

## How do I install these formulae?

Install PagerDuty On-Call Ack directly:

```sh
brew install nithishduda-ai/tap/pagerduty-oncall-ack
```

`brew install nithishduda-ai/tap/<formula>`

Or `brew tap nithishduda-ai/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nithishduda-ai/tap"
brew "<formula>"
```
